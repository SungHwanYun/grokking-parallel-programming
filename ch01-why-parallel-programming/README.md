# Chapter 1 — Why Parallel Programming?

This chapter is conceptual: it explains why the free lunch ended, how Amdahl's and Gustafson's Laws bound speedup, why GPUs became essential, and previews the patterns covered in the rest of the book. The only code shown is a short sequential-vs-parallel pseudocode contrast, so there are no runnable listings here.
